# LIDYA Supabase Auth Email Suite

Production-ready copy and HTML templates for Supabase Authentication emails.

All templates follow the LIDYA luxury email visual system already used by transactional Resend emails: deep plum, warm ivory, restrained gold, serif editorial typography and concise private-client copy.

## Templates

- `confirm-signup.html` — Confirm Email / account activation
- `reset-password.html` — Password recovery
- `change-email.html` — Confirm new email address
- `magic-link.html` — Passwordless sign-in
- `reauthentication.html` — Security verification / reauthentication
- `invite-user.html` — Private client invitation

## Recommended Supabase subjects

- Confirm signup: `Welcome to LIDYA — confirm your private client account`
- Reset password: `LIDYA — reset your password`
- Change email: `LIDYA — confirm your new email address`
- Magic link: `Your private LIDYA sign-in link`
- Reauthentication: `LIDYA security verification`
- Invite user: `Your invitation to LIDYA Private Client`

Paste each HTML file into Supabase → Authentication → Emails → Templates for the corresponding message type. Keep Supabase variables exactly as written.
